paper  Wallet tail

Mirrors a specific wallet's on-chain swaps into simulated paper trades to test whether copy-tailing is viable. "Realistic" fills wait a simulated pipeline delay before pricing, the same way real execution would lag the wallet; "if filled at wallet's price" shows what the same trade would have made with zero lag, isolating how much of the result is pure latency cost.

research · correlation, not proof  Wallet clustering

Attempts to identify likely "side wallets" of a tracked trader by finding other wallets that consistently buy the same tokens shortly before that wallet's public buys. This is statistical correlation, not identity verification — a high score means "consistent with being a controlled wallet," never "confirmed to be." Run via npm run wallet-cluster -- --wallet <address>; results below are read-only. No trades are placed by this module, ever.
